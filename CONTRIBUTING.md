# Contributing

This repository is the public binary-distribution tap. It intentionally does
not contain the application source. Please open issues here for formula,
archive, documentation, or installation problems.

Do not attach DICOM files, screenshots containing patient information, access
tokens, or private URLs. Describe reproducible installation failures with the
release tag, operating system, CPU architecture, and the exact sanitized error.

Changes to `Formula/dicomconvert.rb` are generated by the release pipeline and
should not be edited manually for a published version.
